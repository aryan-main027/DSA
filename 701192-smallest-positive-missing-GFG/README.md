## Medium
You are given an integer array&nbsp;arr[]. Your task is to find the smallest positive number&nbsp;missing from the array.Note: Positive number starts from 1. The array can have negative integers too.Examples:Input: arr[] = [2, -3, 4, 1, 1, 7]
Output: 3
Explanation: Smallest positive missing number is 3.
Input: arr[] = [5, 3, 2, 5, 1]
Output: 4
Explanation: Smallest positive missing number is 4.Input: arr[] = [-8, 0, -1, -4, -3]
