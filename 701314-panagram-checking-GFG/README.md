# [Panagram Checking](https://www.geeksforgeeks.org/problems/pangram-checking-1587115620/1)
## Easy
Given a string&nbsp;s,&nbsp;check if it is a "Panagram" or not.&nbsp; A "Panagram"&nbsp;is a sentence containing every letter in the English Alphabet either in lowercase or Uppercase.Examples:Input: s = "Bawds jog, flick quartz, vex nymph"
Output: true
Explanation: In the given string, there are all the letters of the English alphabet. Hence, the output is true.
Input: s = "sdfs"
Output: false
Explanation: In the given string, there aren't all the letters present in the English alphabet. Hence, the output is false.Constraints:1 ≤ |s| ≤ 104The string may contain any ASCII character.
