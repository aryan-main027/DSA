# [First Repeating Element](https://www.geeksforgeeks.org/problems/first-repeating-element4018/1?utm_medium=article_practice_tab&utm_campaign=article_practice_tab&utm_source=geeksforgeeks)
## Easy
Given an array arr[], find the first repeating element position. The element should occur more than once and the position (from left) of its first occurrence should be the smallest.Note: The position you return should be according to 1-based indexing.&nbsp;Examples:Input: arr[] = [1, 5, 3, 4, 3, 5, 6]
Output: 2
Explanation: 5 appears twice and its first appearance is at position 2 which is less than 3 whose first the occurring position is 3.Input: arr[] = [1, 2, 3, 4]
Output: -1
Explanation: All elements appear only once so answer is -1.
