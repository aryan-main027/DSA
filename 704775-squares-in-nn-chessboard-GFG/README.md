# [Squares in N*N Chessboard](https://www.geeksforgeeks.org/problems/squares-in-nn-chessboard1801/1?sortBy=submissions&category%5B%5D=Numbers&page=1&difficulty%5B%5D=-1)
## Easy
Find the total number of Squares in a N*N chessboard.
&nbsp;
Example 1:
Input:
N = 1
Output:
1
Explanation:
A 1*1 chessboard has only 1 square.
Example 2:
Input:
N = 2
Output:
5
Explanation:
A 2*2 chessboard has 5 squares.
4 1*1 squares and a 2*2 square.

&nbsp;
Your Task:You don't need to read input or print anything. Your task is to complete the function squaresInChessBoard() which takes an Integer N as input and returns the number of squares in a N*N chessboard.
&nbsp;
Expected Time Complexity: O(1)Expected Auxiliary Space: O(1)
&nbsp;
Constraints:1 &lt;= N &lt;= 105
