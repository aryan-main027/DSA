# [Toggle Case](https://www.geeksforgeeks.org/problems/toggle-case/1)
## Easy
Given a string s, convert the characters of the string into the opposite case, i.e., if a character is lowercase, then convert it into uppercase and vice versa.&nbsp;Examples:Input: s = "geeksForgEeks"
Output: GEEKSfORGeEKS
Explanation: The cases of the characters in "geeksForgEeks" are flipped.Input: s = "helloEveryOne"
Output: HELLOeVERYoNE
Explanation: The cases of the characters in "helloEveryOne" are flipped.
